# Changelog

All notable changes to this project are documented in this file.

## [1.0.2] - 2026-11-22

### Changed

- Renamed the vendor, plugin ID, and Java packages from Stormyy to stormizn.
- No behavior changes.

## [1.0.1] - 2026-11-22

### Changed

- Replaced the simplified small-size treatment with direct downscales of the supplied
  coffee-cup artwork.
- The dark background of the source image is transparent in the IDE icon.
- Added the final plugin icon, Marketplace screenshots, and publishing documentation.

## [1.0.0] - 2026-11-22

### Added

- Cup icon for top-level Java classes and records in the Project View and editor tabs.
- Icon handling that leaves interfaces, enums, annotations, and nested declarations unchanged.
- Compatibility with Atom Material Icons through an optional plugin dependency.
