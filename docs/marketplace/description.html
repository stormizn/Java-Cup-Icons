Java Cup Icons gives top-level Java classes and records a coffee-cup icon in the Project View and editor tabs.

Interfaces, enums, and annotation types are intentionally left unchanged, so they keep the distinct icons supplied by your active theme. The result is a clear visual difference between concrete types and the rest of your Java model, without giving up the information the theme already provides.

Features

  • Replaces the icon for top-level Java classes and records in the Project View and editor tabs.
  • Leaves interfaces, enums, annotation types, and nested declarations untouched.
  • Works alongside your active icon theme and other theme icon providers.
  • No settings, theme edits, telemetry, or background services.

Compatibility

Requires IntelliJ IDEA 2026.3 (build 263) and the bundled Java plugin. Atom Material Icons is optional.

Installation

  1. Open Settings | Plugins.
  2. Find Java Cup Icons and click Install.
  3. Restart the IDE.

Notes

The 16 px and 32 px icons are direct downscales of the supplied artwork with its dark background removed. At 16 px, the smallest details naturally compress to the Project View icon size.
